# 🧪 Mecánica Celéste

Este repositorio contiene una colección de simulaciones y notebooks desarrollados para el curso de Mecánica Celeste.

## 📂 Proyectos incluidos

- **[01_Constantes-Movimiento-Sistema-Solar]**: Simulación de dinámica molecular (colisiones elásticas) para reproducir la distribución de Maxwell-Boltzmann.

## 🛠️ Tecnologías utilizadas
- Python 3
- NumPy (Cálculos matriciales)
- Matplotlib (Gráficas estáticas)
- Plotly (Animaciones interactivas)
- Pandas (Manejo de datos)

## 🚀 Cómo usar este repositorio
Puedes abrir cualquiera de los notebooks directamente en Google Colab haciendo clic en los enlaces dentro de cada carpeta.
